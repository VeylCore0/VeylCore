# VeylCore

VeylCore is a FiveM roleplay framework with its own core, inventory, UI and server-authoritative economy. These guides cover installing it, running it, and every resource that ships with it.

* New server: start with **Operations** (install, start order, backups, health check) and **Dependencies**.
* Coming from QBCore / QBox: read **Compatibility** and **Migration**.
* Building your own resources: **API status** and the **UI suite** describe the APIs to use.

The source code lives on GitHub: [VeylCore0/VeylCore](https://github.com/VeylCore0/VeylCore).
